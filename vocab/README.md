# vocab/ — 案由词表

| 文件 | 内容 | 规模 |
| --- | --- | --- |
| `cause_taxonomy_2020_tree.json` | 2020 年修正版《民事案件案由规定》层级树 | 11 / 54 / 473 / 389 = **927** 节点（官方公布 391 个四级，差 2，见下） |
| `cause_taxonomy_2020_nodes.jsonl` | 节点表，每行 `name, level, parent, full_path` | 927 行 |
| `cause_taxonomy_2025_tree.json` | 2025 年修正版（2026-01-01 施行）层级树 | 12 / 59 / 514 / 470 = **1055** 节点 |
| `cause_taxonomy_2025_nodes.jsonl` | 同上，节点表 | 1055 行 |
| `manual_mapping_2020.csv` | 15 条人工核定映射（别名 → 规范名，含父节点与依据） | 15 行 |
| `name_map_2020_to_2025.csv` | 2020 版名称到 2025 版的映射（`name_2020, status, name_2026`，`status ∈ exact/renamed/...`） | 1093 行 |

说明：

- 两版均从最高人民法院官方发布文本（`https://www.court.gov.cn/fabu/xiangqing/282031.html`、
  `.../484231.html`）解析。2025 版 12/59/514/470 与官方公布数字完全一致；2020 版 473 个三级案由的
  1..n 编号连续、无缺号，正文中以“（”开头的四级行恰为 389 条，与官方公布的 391 相差 2 条，属于
  网页正文与公布统计的口径差异，未做硬凑。
- 同名节点（两版各 6 组）：`人格权纠纷`（一级/二级）、`不当得利纠纷`（二级/三级）、
  `无因管理纠纷`（二级/三级）、`海事海商纠纷`（一级/二级）、`侵权责任纠纷`（一级/二级）、
  `第三人撤销之诉`（二级/三级）。映射时取**最深**节点并标记“需人工确认”。
- `manual_mapping_2020.csv` 的 15 条映射优先于任何规则；`scripts/map_labels.py` 是精确匹配与规则修正
  的唯一实现（R1 连续重复片段、R2 去尾“纠纷”、R3 别名表、R4 顿号重排、R5 “A 及 B”拆分、R6 补“纠纷”、
  R7 异议纠纷→异议之诉），**不使用任何嵌入相似度**。
- `name_map_2020_to_2025.csv` 的第三列列名为 `name_2026`，指 2025 年修正版（2026-01-01 施行）。
